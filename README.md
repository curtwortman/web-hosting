# Web Hosting Project

A premium-styled landing page and automated provisioning stack for high-performance web hosting.

## Overview

This repository contains:
- **Landing Page**: A modern, glass-morphism landing page (`index.html` & `style.css`).
- **Provisioning**: A dual-server setup script (`setup.sh`) for Nginx and Apache.
- **Environment Template**: `sample.env` for secure configuration.

## Quick Start

For detailed instructions on setup, configuration, and deployment, please see the [Documentation](docs/README.md).

1. **Clone the repo**
2. **Configure environment**: `cp sample.env .env`
3. **Run setup**: `sudo ./setup.sh`
